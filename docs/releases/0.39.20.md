# 여백 PC 0.39.20

글꼴 목록을 열면 이름마다 해당 글꼴의 모양을 볼 수 있습니다. 기본모드에서 24개, 간편모드에서 20개 항목을 비교할 수 있고, 목록 미리보기는 오프라인에서도 작동합니다.

- 간편모드에서 여섯 가지 디자인을 고르고 글꼴·굵기·크기를 조절할 수 있습니다.
- 오늘과 내일의 할 일, 날짜별 개인 공지를 한 화면에서 관리합니다. 항목 옆 **수정**으로 제목과 형광펜을 바꿀 수 있고, 공지는 체크해도 같은 자리에 남습니다. 할 일 위젯에서도 제목을 수정할 수 있습니다.
- 로그인한 계정의 할 일 제목과 완료 상태는 같은 계정의 지원 기기에 동기화됩니다. 개인 공지와 형광펜은 이 PC에 저장됩니다.
- 간편 월간 다이어리에서 일정 제목을 누르면 수정하고, 날짜의 빈 곳을 누르면 추가합니다. 여러 날에 걸친 일정의 제목을 고쳐도 기간이 유지됩니다. 개인 할 일과 공지는 월간 달력과 분리됩니다.
- 달력에서 토요일 날짜는 파란색, 일요일과 대한민국 공휴일은 빨간색으로 표시합니다. 일정은 선택한 파스텔색으로 제목의 배경을 채웁니다.

기존 사용자는 앱의 업데이트 다운로드가 끝난 뒤 **재시작**을 선택하면 적용됩니다.
