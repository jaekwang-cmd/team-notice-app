# 여백 PC 0.39.13 · 비교시트 펼침 및 AI 연결 개선

한 시트만 사용할 때 금융사 목록을 길게 펼치고, 차량 정보를 접어 비교할 공간을 넓혔습니다.

- 단일 시트에서 금융사 전체 목록을 표시하며, 긴 화면은 페이지에서 스크롤합니다.
- 차종·차량가·초기자금·할인 입력칸을 따로 접고 펼칠 수 있습니다. 입력값과 접힘 상태를 유지합니다.
- 큰 창에서도 월 납입금·잔존가치·계약기간·총 인수비용과 순위가 정상 표시되도록 가로폭을 수정했습니다.
- AI 실행 시 개인 API 키를 다시 읽도록 개선하고, 설정 파일 읽기 오류와 키 미설정 안내를 구분했습니다.

검증: 비교시트 전체 5열/15개 금융사 표시, 4가지 창 크기, 금액 입력·합계·순위·접힘 상태 유지 검사 및 기존 레이아웃 10개 통과. 설치된 PC 앱의 실제 비교시트 화면 확인 완료. 개인 키 읽기 회귀 검사와 기존 Terra 실 API 응답 확인 완료. 기존 장부 계산과 데이터는 유지합니다.

0.39.11~0.39.13의 로컬 변경을 함께 제공합니다. 공개 파일에 OpenAI 비밀 키를 포함하지 않습니다. 모바일 업데이트는 포함하지 않습니다.
