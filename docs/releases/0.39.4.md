# 여백 PC 0.39.4 · 장부 입력과 월 목표

장부의 반복 입력 흐름을 정리하고, 기존 계산·엑셀·보고 기능을 유지했습니다.

- 작은 직접 추가 버튼과 AI로 출고건 추가하기 버튼. 직접 추가·수정은 오른쪽 패널에서 확인 후 저장합니다.
- AI 신규 결과는 입력 패널로 가져와 수정한 다음 최종 등록합니다. 기존 건 AI 수정도 유지합니다.
- 고객명 앞 DB 유형 열과 패널 입력칸, 행별 수정 버튼을 추가했습니다.
- 선택 월의 인정 대수 / 월 목표를 표시합니다. 100% 초과분도 계속 계산하며 눈금이 확장됩니다. 목표는 계정별·월별로 이 PC에 저장됩니다.
- 기존 금융·정산 필드, 엑셀 출력, 직책·연락처, 이월, 보고·안내문 기능을 유지하고 세로 간격을 줄였습니다.
- 실시간 장부 갱신을 합치고 편집 중 표 교체를 미룹니다. 행별 쓰기를 순서대로 처리하며 동시 쓰기를 제한합니다.
- 날짜·일정 글씨를 최대 30px로 키우고, 큰 글씨에 맞춰 달력 높이를 조정합니다.
- Google 로그인 진입점을 각 화면 상단에서 찾을 수 있습니다.

검증: Node 38, 기존 UI 37, 레이아웃 10, 풍경 16, 로그인 UI 8 통과. 신규 장부 UI에서 목표/월 이동, DB 열 순서, 추가·수정·취소, 저장 실패 후 재시도, AI 단계별 저장, 기존 정산 배열 보존을 검증했습니다. 입력 반응성과 30px 글씨 저장·작은 창 표시 검사도 통과했습니다. 실계정에 테스트 장부를 쓰거나 외부 AI 유료 호출을 수행하지 않았습니다.

공개 설치 파일에는 OpenAI 비밀 키를 포함하지 않습니다. 기존 설치의 키는 업데이트 시 같은 사용자 PC의 기존 프로필로 이전해 유지합니다. 새 PC에 처음 설치하는 경우 AI는 별도 로컬 키 설정이 필요합니다. Google/Firebase 클라이언트 설정과 기존 사용자 프로필 경로는 유지합니다.
