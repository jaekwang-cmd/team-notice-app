# 여백 0.39.3 · 풍경이 살아 있는 다이어리

- 아홉 가지 테마와 각 테마의 세 풍경을 다듬고, 동물·나뭇잎·꽃·물결이 움직이는 배경을 더했습니다.
- 오늘의 페이지, 메모, 고객 리마인더, 정산장부와 비교시트를 종이 카드와 책갈피 메뉴로 새롭게 구성했습니다.
- 왼쪽 메뉴를 접어 작업 공간을 넓힐 수 있습니다. 비교시트도 한 장씩 접고 펼칠 수 있으며 입력한 내용은 유지됩니다.
- 작은 창에서는 비교시트를 세로로 배치하고 스크롤로 모든 항목에 접근할 수 있습니다. 월간 달력은 일정이 많은 주의 높이를 확보하고, 날짜를 선택하면 상세 카드가 열립니다.
- 정산장부의 연속 입력·금융사 선택과 달력 새로고침·색상 선택의 안정화를 포함합니다.

기존 Google 연결, 계정별 데이터, 일정과 메모, 장부 계산 및 엑셀 출력 경로를 유지합니다. 이번 릴리스는 Windows PC용입니다.

검증: Node 회귀 검사 37개, 실제 PC 렌더러를 사용하는 메모리 예시 데이터 UI 검사 63개 통과. UI 검사는 9개 테마·27개 풍경, 1440/1080/860px 창 너비, 일정 편집, 장부 입력, 비교 계산과 접기 상태 보존을 포함합니다. 실계정의 클라우드 동기화·엑셀 출력 전체 과정을 새로 실행한 검증은 아닙니다.

설치 프로그램 또는 앱의 자동 업데이트로 설치할 수 있습니다. 기존 사용자 프로필을 유지합니다.
